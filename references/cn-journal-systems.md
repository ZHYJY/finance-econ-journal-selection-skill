# 中文期刊评价体系与核验入口

用于判断中文路线的"这个刊算什么档次"到底由谁定义。核心原则：**任何体系都只对发布机构的当期目录负责，不能跨体系换算，也不能替代院校认定。**

## 体系清单

| 体系 | 发布方 | 结构 | 常见误用 |
|---|---|---|---|
| CSSCI（南大核心） | 南京大学中国社会科学研究评价中心 | 来源期刊目录 + 扩展版 + 集刊，按学科分列 | 把"扩展版"当"来源期刊"；把"集刊"当正刊 |
| 北大核心 | 北京大学图书馆《中文核心期刊要目总览》 | 按学科分编，数年一版 | 用第三方网站标签代替正式目录；不区分版次 |
| AMI 综合评价 | 中国社会科学评价研究院 | 顶级 / 权威 / 核心 / 扩展（按学科与刊型） | 与 CSSCI 混用；把 AMI 核心说成"南大核心" |
| CSCD | 中国科学院文献情报中心 | 来源期刊 + 扩展库，偏自然科学 | 拿 CSCD 给纯经济学刊背书 |
| 中国科技核心（统计源） | 中国科学技术信息研究所 | 自然科学与部分社科 | 与 CSSCI 视为同档次 |
| 中科院分区 | 中国科学院文献情报中心 | 大类/小类 1–4 区，另有 Top 标注 | 与 JCR 分区互换使用 |
| JCR 分区 | Clarivate | 按学科类别 Q1–Q4，基于期刊影响因子 | 把 JCR Q1 说成"中科院 1 区" |
| 复合影响因子 | 知网等中文数据库 | 中文期刊自建指标 | 与国际期刊的 JCR IF 直接比大小 |

## 判定规则

1. **先问口径**：用户说"核心"时，追问是 CSSCI 来源、CSSCI 扩展、北大核心、AMI 核心，还是单位内部目录。四种答案导向完全不同的候选池。
2. **再问版本**：目录分版次。毕业或考核要求通常绑定"本人适用年度的目录"，晚一版可能改判。目录版本必须写成 `目录名 + 版次/年份 + 生效范围`。
3. **单位优先**：院校科研处、研究生院、人事处公布的认定文件效力高于任何第三方口径。同一刊在 A 校算 top、在 B 校只算普通，这是常态，不是数据错误。
4. **不叠加**：CSSCI 来源 + 北大核心 + AMI 核心是三个体系的三个结论，不能相加成"更高级"，也不能互相抵偿。
5. **不推算**：不能因为某刊是 CSSCI 来源就推断它是 AMI 核心，反之亦然。每一个都要独立核验。
6. **区分刊型**：正刊 / 扩展版 / 集刊 / 增刊 / 网络首发，在多数单位认定中待遇不同。中文刊的"网络首发"通常不等于正式见刊。

## 核验入口

- CSSCI：南京大学中国社会科学研究评价中心官网（`cssrac.nju.edu.cn`），以正式目录文件为准，不用二手汇编。
- 北大核心：北京大学图书馆官网及《中文核心期刊要目总览》正式出版信息。
- AMI：中国社会科学评价研究院官网的当期评价报告。
- 中科院分区：官方分区表平台（`fenqubiao.com`），注意区分大类/小类与升级版口径。
- JCR：Clarivate 期刊引证报告与 Master Journal List（`mjl.clarivate.com`）。
- CSCD：中国科学院文献情报中心官网。

每次核验记录：`体系｜版次｜学科分类｜该刊所在位置（来源/扩展/集刊/分区区间）｜来源URL｜核实日期`。

## 中文路线的额外约束

- **刊期与见刊**：中文刊常有排版周期与组稿偏好（专题、笔谈、会议论文专辑）。见刊时间只能通过编辑部或已刊论文的收稿/录用日期推断，且必须标注为推断。
- **篇幅与格式**：中文刊字数上限、摘要结构、注释体例、作者简介格式差异大，投稿前必须读当期《稿约》。
- **署名与基金**：中文刊普遍要求标注基金项目与作者单位，且对基金层级敏感；不要把英文刊的双盲匿名习惯直接套用。
- **一稿一投**：中文刊同样执行一稿一投，不接受同时投两家。部分刊允许"会议论文改写"，需以刊方说明为准。
- **语言路线不互斥**：同一篇稿可以规划"中文先发、英文改写再发"或反之，但必须核实目标刊关于先前发表（prior publication）与预印本的政策，改写比例要能通过查重。
