# 拒稿后的改投决策

拒稿信的类型决定下一步动作。**先定性，再改稿，最后才谈降档。**

## 第一步：给拒稿定性

| 类型 | 特征 | 首轮动作 |
|---|---|---|
| Desk reject · scope 不符 | 编辑明确指出不在范围、读者不匹配 | 换读者结构相近的刊，不改研究设计 |
| Desk reject · 格式/材料 | 字数、图表、格式、披露缺失 | 补齐材料，可原档位重投同档刊 |
| Desk reject · 贡献不足（编辑判断） | "insufficient contribution"、"not enough novelty" | 需要重估定位：是贡献表述问题还是贡献本身问题 |
| 外审拒稿 · 致命缺陷 | 识别策略失效、数据不可信、结论与证据不符 | 停止投递，先修复设计与证据，不得原样改投 |
| 外审拒稿 · 可修复问题 | 稳健性不足、机制未讲清、文献定位错 | 按意见修复后，可原档位或相邻档位改投 |
| Reject and resubmit（R&R 变体） | 明确邀请重投同刊 | 这是一次重新投稿，不是新论文，按同刊要求重做 |
| 编辑转投邀请（transfer） | 出版社内部转投 | 看清楚是"转投同社另一刊"，仍需按新刊 scope 与格式重审，不等于录用 |

不要把"审稿人没看懂"自动归因为读者太窄；先判断是写作问题还是贡献问题。

## 第二步：修复与降档的取舍

- **先修复再看档位**：识别、测量、理论错误不修复就改投，等于把同一个缺陷搬去下一家，多数会在第二轮被同一类意见打回。
- **不因一次拒稿自动降档**：单次拒稿是样本量为 1 的信号。判断降档要看：拒稿理由是否指向定位（scope/读者），还是指向质量（设计/证据）。
- **最多连续两次同档改投**：同一档位连续两次因同类理由被拒，应考虑改定位（换读者、换问题切口）而不是继续平行投。
- **降档不等于降标准**：低一档的刊可能更看重机制细节与政策含义，改写重点随之变化，不是把稿子原样搬过去。

## 第三步：改投路线的时间账

只有**投稿截止**可以用日程控制；**录用、online first、正式见刊**只能评估风险。做时间账时把假设写出来：

```
剩余时间 = 截止日期 - 今天
单轮周期假设 = [未核实] 首轮 X 周 + 修回 Y 周
可容纳轮次 = 剩余时间 ÷ 单轮周期（向下取整，且需减去材料准备时间）
```

- 周期数值必须标注来源（刊方平均、第三方统计、作者经验），且标记 `未核实`。
- 不承诺"一定赶上"。给的是风险等级与最晚决策日期。
- 若最晚决策日期已过，动作应是"换可在截止前完成的方案"，而不是压缩审稿流程。

## 第四步：记录

每次改投保留一条记录：`原刊 → 拒稿类型 → 主要意见 → 实际修改项 → 新刊 → 适配变化 → 费用变化 → 时间变化`。同一篇稿的三次以上改投，必须能说清每一跳改了什么，否则就是盲目平移。
