# 投稿材料与合规清单

选刊结论只有落到"能不能在截止前把材料递出去"才算可执行。本文件按刊型给清单，每一项状态只能是 `已备 / 待补 / 不适用 / 未知`。

## 通用清单

| 项目 | 判定要点 | 常见坑 |
|---|---|---|
| 稿件正文 | 字数、图表数、参考文献格式、模板 | 用旧模板；图表数超限被 desk reject |
| 摘要与关键词 | 结构式 vs 叙述式；关键词数量上限 | 中文刊常要 3–5 个且要求与 JEL 呼应 |
| Cover letter | 贡献陈述、适配说明、推荐/回避审稿人 | 把通用模板发给所有刊；AFA 页面明确提醒不要默认各家都要通用投稿信 |
| 作者信息页 | 单位、职称、通讯方式、ORCID | 双盲刊要求正文与元数据都去标识 |
| 利益冲突 / 伦理 | 财务披露、机构审查、人类被试审批 | 用商业数据库要写数据许可与使用范围 |
| 数据与代码可得性 | 公开仓库、受限数据访问说明、复现包 | AEA 等刊对非公开数据有专门处理流程，不能一句"数据可索取"糊过去 |
| 作者贡献 | CRediT 或刊方自定义分类 | 中文刊多用"作者贡献"段落而非分类标签 |
| 推荐审稿人 | 数量、回避规则、利益冲突 | 推荐同单位或近期合作者会被质疑 |
| 投稿费 / APC | 币种、是否可申请 waiver、付款时点 | 把"非 OA"等同于"全程免费" |
| 预印本与传播 | SSRN/arXiv/机构库是否允许 | 部分刊要求投稿时申报预印本 |
| 查重与相似度 | 中文刊普遍查重，英文刊看重自我重复 | 与自己已发表内容重复未引用会被判 self-plagiarism |

## 英文实证刊

1. 主文档匿名版 + 标题页（多数金融经济刊走双盲或单盲，以刊方说明为准）
2. 摘要 ≤ 刊方上限（常见 100–200 词，须现查）
3. 图表单独文件或内嵌，按刊方编号规则
4. Internet Appendix / 补充材料（稳健性、变量定义、样本筛选）
5. Data and code availability statement（含受限数据申请路径）
6. 复现说明：软件版本、随机种子、运行顺序
7. Disclosure statement（ funding、consulting、board seat 等）
8. Cover letter（贡献 + 与刊 scope 的对应 + 与近期该刊论文的对话）
9. 推荐审稿人（如允许）

## 中文刊

1. 按当期《稿约》的体例排（摘要结构、注释、参考文献、作者简介格式差异极大）
2. 基金项目名称与编号（层级影响初审印象，但不能因此虚构）
3. 中图分类号 / 文献标识码 / JEL（如刊方要求）
4. 英文标题与摘要（多数刊要求）
5. 作者简介与联系方式（中文刊一般不双盲）
6. 查重报告（部分刊要求作者自附）
7. 版权转让或独家代理协议（录用后签署）

## 递送前的最后三问

1. **硬门槛是否全部通过**：身份、scope、刊型、语言、格式、费用都能确认吗？有未知就不能说"可以投"。
2. **时间是否真的够**：截止事件是投稿、录用、online first 还是正式见刊？只有投稿截止才可能靠日程控制，录用与见刊只能评估风险。
3. **材料是否同一版本**：正文、图表、附录、cover letter 里的样本量、结论、变量名是否一致？版本不一致是常见 desk reject 原因。
